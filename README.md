# Voice Chat Interview System

A voice-based interview system using speech-to-text (faster-whisper) and Claude AI for intelligent conversation flow.

## Features

- **Voice Input**: Automatic silence detection stops recording after 2 seconds of silence
- **Speech-to-Text**: Local transcription using faster-whisper
- **Adaptive Follow-ups**: Claude AI scores answers on Specificity and Problem-solving, asking up to 2 follow-up questions per topic when needed
- **Interview Summary**: Post-interview summary generated by Claude based on per-question scores and transcript
- **Progress Tracking**: Visual progress bar and question counter
- **Real-time Feedback**: Live audio level visualization

## Architecture

```
Browser (Frontend)
  ↓ Audio Blob (on silence)
FastAPI (Backend)
  ↓ Audio File
faster-whisper (STT)
  ↓ Transcription
Claude AI (Turn evaluator — scores S/P, decides follow-up or advance)
  ↓ Response + State
Frontend (Display)

On completion:
Claude AI (Summary generator — produces per-question feedback report)
```

## Setup

### Prerequisites

- Python 3.13+
- ANTHROPIC_API_KEY environment variable

### Installation

1. Install dependencies:

```bash
uv sync
```

2. Set your Anthropic API key - copy `.env.example` to `.env` and update the value:

```bash
cp .env.example .env
```

### Running

1. Start the backend server:

```bash
make run
```

2. Open your browser to:

```
http://localhost:8000
```

## Usage

1. Click "Start Interview" to begin
2. Click the microphone button to start recording
3. Speak your answer
4. The system automatically detects when you stop speaking (2s of silence)
5. View the transcription and Claude's response
6. Follow-up questions are asked if your answer lacks specificity or problem-solving depth (max 2 per question)
7. Progress automatically to the next question when your answer is complete
8. After all questions, request a summary via `GET /api/summary?session_id=<id>`

## Customization

### Changing Questions

Edit `backend/assets/questions.json`:

```json
{
  "questions": ["Your question 1", "Your question 2"]
}
```

### Adjusting the Interview Prompt

Edit `backend/assets/prompt_tmpl.txt` to change how Claude evaluates and responds to answers.

Edit `backend/assets/summary_prompt_tmpl.txt` to change the format of the post-interview summary.

### Adjusting Whisper Model

In `backend/app.py`, change the model size for better accuracy (slower) or speed:

```python
# Options: "tiny", "base", "small", "medium", "large-v2"
whisper_model = WhisperModel("base", device="cpu", compute_type="int8")
```

### Silence Detection Settings

In `frontend/assets/script.js`, adjust these constants:

```javascript
const SILENCE_THRESHOLD = 20; // Lower = more sensitive
const SILENCE_DURATION = 2000; // Milliseconds
```

## Technologies

- **Backend**: FastAPI, faster-whisper, Anthropic Claude
- **Frontend**: Vanilla JavaScript, Web Audio API, MediaRecorder API
- **STT**: faster-whisper (local, no API costs)
- **LLM**: Claude Sonnet 4.6

## Notes

- First run will download the Whisper model (~150MB for base model)
- Audio is processed server-side and not stored permanently
- Conversation state is stored in-memory (use Redis/DB for production)
- Each question allows 1 initial answer + up to 2 follow-ups before automatically advancing
